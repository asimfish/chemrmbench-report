# ChemRMBench：系统验收与当前边界

目标是一个基于 SafeLab 环境、可复现地测量事件记忆和操作时间的基准。
Paper A 保持策略冻结，独立裁判只读；经验学习与策略吸收属于 Paper B。

| 层 | 已有实现与本轮交付 | 尚缺的正式证据 |
| --- | --- | --- |
| 场景与物理 | 重建实验室原生录像、65 实体阶段状态、SafeLab/Isaac 接口与安全约束 | 独立几何/接触/流体/化学标定，跨任务可重复性 |
| 任务生成 | 结构化任务 DAG、语义前置/后置条件、冻结 manifest、三类 public graph split | 真正改变物理任务的 held-out 组合与拓扑；图标签不是物理泛化 |
| 记忆 | 显式事件记忆、保留/清空读出历史、原事件期限账本 | 随机独立父试次、相同当前输入的物理配对、像素可察觉性及泄漏检查 |
| 时间 | 命令/观察/实际接触区间区分；失败与恢复不重设原期限 | 化学事件独立传感器标定；连续运行与暂停时钟分别验收 |
| 长任务 | 分段 journal、八阶段状态存档、父子源与游标绑定、重建前拒绝门 | 普通冷恢复仍仅 1/8 边界；流体及隐藏 PhysX 状态恢复尚未通过 |
| 执行与裁判 | 本轮统一批量入口、全任务预检、每任务证据、离线重新判分与重新汇总 | 像素/Isaac 后端还需接到统一入口并按各自原生门验收 |
| 数据发布 | 原生录像、逐帧映射、阶段状态、CSV/图/PDF、原始失败与哈希保留 | 正式任务数据卡、独立样本量与划分冻结、verifier FP/FN 审计 |
| 基线 | 三种 CPU 后端的参考策略和弃权对照 | 匹配骨干/预算的真实模型比较、多随机种子及置信区间 |

当前统一入口支持 `graph-contract`、`task-contract`、`thermal-dose`。
它们的成功是软件合同或未标定过程模型结果，不计正式机器人、化学或 M1 样本。
C13 合同的 seed/步进结构也不能用于声称真实记忆能力。参考策略知道任务合同，
不存在“打通软件接口就证明模型学会”的推论。

V100 的七个严格终态通过属于一次私有固定输入对照。不能以七个阶段当七次独立试验，
不能向受测 agent 暴露未来控制输入，也不能把其通过追加到普通冷恢复覆盖。
V99 原失败继续保留。系统与论文均不得将阶段存档、投影或视频作为隐藏物理状态恢复的证明。

下一原生研究仍是 V101：同一真实父试次、相同当前图像/关节/目标包，
只干预已观察事件的历史记忆，实际执行或明确拒绝，并以原事件与实际操作区间判分。
必须先完成事件随机化可行性、当前输入相等与泄漏、opaque actor 上下文、
时钟策略、独立读出器、资源上限及前瞻性源封存。本轮不启动新原生或模型工作。

完整基准完成条件是上表所有正式证据就绪，再冻结任务、划分、策略、裁判和统计方案，
以真实模型在原生场景完成主表、消融、失败分析、FP/FN 与复现验收。
CPU 合同运行数和测试数量都不能代替这些验收。
