# Decision: six capability profiles with orthogonal chemical timing operators

Amended 23 October 2026: the primary organization is now protocol family ×
three task scopes; see [experimental design](experimental_design.md). Six
profiles remain compatible labels, not a total difficulty ordering. This
revises organization and experiment design, not the existing classifier or
any task verdict. Scientific time roles, process logic, memory and batching
are independent descriptors. Complete protocols require attributable results.

The alternatives were (A) further subdividing the six-level ladder, and (B)
separating task scope from process/information requirements. Choose B: it
allows nested experiments and interpretable comparisons without invalid
untimed chemistry or arbitrary difficulty claims. Cost: no single tier number
summarizes difficulty; report the coordinates and performance components.

Status: implemented design schema; native chemical expansion remains unqualified.
Date: 23 October 2026.

The user explicitly requests atomic, timed atomic, local composition, chemically
timed/logical composition, full experiments and time-sensitive full experiments.
The previous five-family matrix is useful for controls but insufficient as the
primary hierarchy. Preserve existing data and all frozen v0.1 scientific rules.

| Candidate | Benefit | Limitation |
|---|---|---|
| Keep only the five-family M/T grid | Matched contrasts remain simple | Does not distinguish primitive control from a complete experiment |
| Copy LabUtopia's five levels | Familiar structural progression | Moves generalization into one tier and adds mobile scope absent from this runtime |
| Six reported profiles over three structural scales, with timing/process obligations, memory and generalization horizontal | Matches the requested progression and preserves independent factors | Needs explicit semantic granularity and protocol-completeness rules |

Choose the third. Do not equate archive count with operation count, or length
with experimental completeness. Keep goal milestones in the existing TaskProgram
DAG; future conditional chemistry uses a benchmark-owned process model and
measured event contracts. Do not replace independent verifiers with controllers'
phase labels. The new classifier evaluates specifications, never policy success.

Source protocol values, engineering tolerances and accelerated process-clock
values have different provenance. A documented method does not calibrate a
simulator. Proposed cases remain `source_grounded_design` until physical,
process and observation validation exist. Existing native timing scores and
thresholds are unchanged. Synchronization, periodic acquisition and chemistry
models are explicit implementation gaps, not implied by their catalogue entries.

Observable acceptance: six profiles with full-scope guardrails, ten timing
types, traceable source parameters and conditions, no new native claim, unchanged
legacy registry, and public documentation that distinguishes actual seven-task
evidence from proposed chemistry. New time-scaling settings cannot silently
alter robot or safety clocks. No new GPU or model calls are part of this change.
